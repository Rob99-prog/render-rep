# render-rep
## 📌 Descripción
Aplicación web desarrollada en **Python con Streamlit** para la visualización de datos.  
Incluye funcionalidades como:
- Manejo de sesiones de usuario.
- Visualización de tablas interactivas con checkboxes.
- Organización y estandarización del código usando **Pylint** y **Black**.

---

## 🛠️ Tecnologías usadas
- Python
- Streamlit
- Pylint / Black (formateo y estilo de código)

---

1. Clonar este repositorio:  
   ```bash
   git clone https://github.com/Rob99-prog/render-rep.git

   Entrar en la carpeta del proyecto:

cd render-rep

Ejecutar la aplicación en Streamlit:
